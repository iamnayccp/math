1. Calculer le terme \(u_1\). / Donner la valeur exacte de \(u_1\) et de \(u_2\). / Calculer \(w_0\). ▼
Données :
\[ u_n = \frac{3n^2+2n-1}{2n^2-5n+4} \]
\[ w_n = 2n+3 \]
Calcul de \(u_1\) :
\[ u_1 = \frac{3(1)^2+2(1)-1}{2(1)^2-5(1)+4} \]
\[ u_1 = \frac{3+2-1}{2-5+4} \]
\[ \boxed{u_1=4} \]
Calcul de \(u_2\) :
\[ u_2 = \frac{3(2)^2+2(2)-1}{2(2)^2-5(2)+4} \]
\[ u_2 = \frac{12+4-1}{8-10+4} \]
\[ \boxed{u_2=\frac{15}{2}} \]
Calcul de \(w_0\) :
\[ w_0 = 2(0)+3 \]
\[ \boxed{w_0=3} \]
8. Déterminer / Calculer la limite de la suite \((u_n)\). ▼
Données :
\[ u_n = \frac{3n^2 + 2n - 1}{2n^2 - 5n + 4} \quad \quad n \in \mathbb{N} \]
\[ \lim_{n \to +\infty} n = +\infty \]
Calcul :
\[ \lim_{n \to +\infty} u_n = \lim_{n \to +\infty} \frac{3n^2 + 2n - 1}{2n^2 - 5n + 4} \]
\[ = \lim_{n \to +\infty} \frac{3 + \frac{2}{n} - \frac{1}{n^2}}{2 - \frac{5}{n} + \frac{4}{n^2}} \]
\[ = \frac{3 + 0 - 0}{2 - 0 + 0} \]
\[ \boxed{\lim_{n \to +\infty} u_n = \frac{3}{2}} \]
